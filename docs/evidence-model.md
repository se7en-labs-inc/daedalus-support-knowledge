# Evidence and confidence model

| Classification            | Meaning                                                                       |
| ------------------------- | ----------------------------------------------------------------------------- |
| `officially-documented`   | Publisher documentation or release material directly supports the claim.      |
| `maintainer-confirmed`    | An identifiable maintainer confirms it.                                       |
| `independently-confirmed` | Multiple independent community accounts support the same observation/outcome. |
| `single-user-confirmed`   | One reporter confirms an outcome.                                             |
| `plausible-unverified`    | Technically plausible, but not confirmed.                                     |
| `conflicting`             | Material observations or outcomes disagree.                                   |
| `deprecated`              | Once applicable; no longer recommended for current releases.                  |
| `known-incorrect`         | Evidence establishes that the claim is wrong.                                 |
| `unsafe`                  | The procedure creates unacceptable risk.                                      |

Confidence is `high`, `medium`, `low`, or `none`. Editors record a rationale, considering source authority, independence, directness, version fit, reproduction, and freshness. Classification cannot be “upgraded” from community to official merely because many users agree. Unsafe and known-incorrect content is retained only to prevent recommendation.
